Audit date: 2026-11-12
Baseline inspected: `feat/v0.7.0-trust-speed-and-viewing` (`70d13ed`, plus CI artifacts from `42900272810` and `42900255069`)
Severity scale:
- **S1**: Data loss, privacy leak of originals, or unhandled process crash in common flows
- **S2**: Blocks a core job, corrupts catalog/organization, or misleads user on data/safety state
- **S3**: Noticeable friction, inconsistency, missing clarity, or documentation/CI gap
- **S4**: Polish

Rules:
- Every S1 and S2 item must be resolved before shipping a release candidate.
- Status tracks progression through `Open` -> `Fixed` -> `Verified` (or `Accepted / Deferred` only for S3/S4 with recorded decision).
