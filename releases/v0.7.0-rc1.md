# Luma v0.7.0 Release Candidate 1 (Stabilization Build)

Important: **Portable Windows x64 build (`Luma-v0.7.0-rc1-win-x64.zip`).** This binary is **unsigned**; on first launch Windows Defender SmartScreen will show a warning ("More info -> Run anyway"). Verify the attached `SHA256SUMS.txt` digest before launching.

## What Changed for Everyday Use

### Reliability, Data Safety, and Trust Fixes
- **Fixed first-run empty state:** Brand-new libraries now clearly display **"A little room for memories"** with the **Add folder or drive** button and drag-drop prompt.
- **Multi-word tag protection:** Tags with spaces (such as `Family Trip` or `Old Dhaka`) are preserved cleanly across Tag Manager, rename, merge, and bulk tagging.
- **Quote-aware search:** Filters like `tag:"Family Trip"`, `location:"New York"`, and `folder:"2025/Trips"`, plus multiple combined `tag:` tokens, now match accurately.
- **Honest catalog repair & WinUI dialog crash elimination:** Corruption repair removes stale `-wal`/`-shm` sidecars before restoring `.bak` backups and honestly distinguishes a restored backup from a freshly reinitialized empty catalog. Modal dialogs route through `ShowDialogAsync` to prevent WinUI 3 `UIAffinityReleaseQueue` (`0xc000027b`) crashes under Narrator/UIA, and `RefreshGallery` avoids synchronous layout re-entrancy crashes.
- **Delete & Rename safety:** Cancelling Windows' Recycle Bin dialog no longer skips items or forces a full rescan; confirmed deletes clean catalog rows immediately. Rename blocks Windows reserved device names (`CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`), handles NTFS case-only renames safely, confirms extension edits/removals, and checks drive connectivity before Undo move while keeping tags and albums intact.
- **Low-disk warm offline reads:** Systems with `< 500 MB` free space continue rendering already-cached `.thumb` previews offline while pausing new cache writes cleanly.
- **Privacy & XMP hardening:** Error diagnostics in `last-error.txt` redact personal folder paths consistently; XMP parsing prohibits XML DTD processing explicitly.
- **Clipboard lock clarity:** Clipboard copy/path/diagnostic failures caused by lock screens or clipboard contention retry automatically and report clear guidance toward `Copy to folder / Move to folder`.

### Usability, Navigation, and Help
- **Saved browse position & offline filter survival:** Restoring scroll anchor and inset across restarts now works across Grid, Adaptive, and Moments views cleanly (`VisibleAnchor` prefers unclipped top items), and restoring `Source + Folder + Month` offline keeps the active Month filter intact.
- **Quick Preview focus & video clarity:** Opening Quick Preview moves keyboard focus cleanly inside the overlay (`Left`, `Right`, `F`, `T`, `M`, `I`, `Space`, `Del`, `Esc`) and surfaces a visible `"Video frame · Press Enter or Open to play in default app"` cue.
- **In-app Help, Reset, and Feedback:** Press `F1` or visit **Settings** for **Keyboard shortcuts & tips**, **Reset catalog (keep originals)...**, and privacy-respecting **Send feedback / Report a problem...** (opens a prefilled GitHub issue only when confirmed).

## Installing & Upgrading from v0.6.0
1. Close any running instance of Luma.
2. Extract the entire ZIP into a fresh folder (`C:\Apps\Luma`); do not run `Luma.App.exe` from inside the ZIP preview.
3. All existing sources, tags, favorites, virtual albums, exclusions, settings, and cached thumbnails in `%LOCALAPPDATA%\Luma` carry forward automatically without re-importing.
