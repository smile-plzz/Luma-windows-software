# Luma v0.7.0: Trust, Stability, and Everyday Polish

Important: **Portable Windows x64 build (`Luma-v0.7.0-win-x64.zip`).** This binary is **unsigned**; on first launch Windows Defender SmartScreen will prompt ("More info -> Run anyway"). Verify against `SHA256SUMS.txt` before extracting.

## Highlights for Users

- **Fix-first stabilization release:** Resolves first-run onboarding visibility, eliminates WinUI 3 `ContentDialog` teardown crashes under accessibility/UIA clients (`0xc000027b`), protects multi-word tags (`"Family Trip"`), supports quote-aware search (`tag:`, `location:`, `folder:`), preserves tags/favorites/albums across Move Undo, prevents Delete-cancel skips, blocks Windows reserved filenames on rename, keeps offline `Source + Folder + Month` filters intact on restart, and preserves scroll position across Grid, Adaptive, and Moments layouts.
- **Clearer viewing, cached Map & responsive loading polish:** Collapsible sidebar (`Ctrl+B`) and toolbar (`Ctrl+H`), Windows 11 Mica translucent sidebar & GPU-composited hover micro-interactions with video duration pills, Adaptive & Moments rows, Photo Stacks with cover-item clarity tooltips, direct opening in your preferred Windows viewer or player (`Enter`, double-click, or Map **Open**), **Tag Manager**, **Duplicates Finder**, **Smart Collections**, transparent progress locks during heavy tasks (preventing mid-load freezes or `cache.lock` confusion), and privacy-first offline **Photo Map** backed by persistent SQLite & in-session metadata caching (online tiles remain opt-in per session).
- **Stronger trust & help:** Honest catalog corruption recovery messages, path-redacted error diagnostics (`last-error.txt` and `crash.log`), warm cache reads on low disk space, Settings **Reset catalog (keep originals)...**, **`F1` Keyboard shortcuts**, **Send feedback / Report a problem...**, plus standalone User Guide, Troubleshooting, and Known Limits docs.

## Upgrading from v0.6.0
Close Luma, extract the complete ZIP into a writable folder beside bundled `.dll`/`.pri` files and `Assets/`, and launch `Luma.App.exe`. Your existing `%LOCALAPPDATA%\Luma` catalog, tags, favorites, albums, exclusions, and preferences upgrade automatically without re-scanning originals.
